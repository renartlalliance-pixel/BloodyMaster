BLOODYMASTER 0.3.8 - VERSION DE TEST WINDOWS X64

1. Fermer FL Studio puis lancer l'installateur.
2. Le VST3 est copie dans :
   C:\Program Files\Common Files\VST3\Bloody Master.vst3
3. Ouvrir FL Studio, Options > Manage plugins > Find installed plugins.
4. Rechercher Bloody Master et le charger sur un insert du Mixer.
5. Commencer avec le volume de monitoring habituel et un mix non limite.
   Choisir un preset puis ajuster le niveau entrant, Drive, Clip et Hammer.

DSP disponibles : HPF/LPF, EQ de couleur, 3 bandes parametriques, Gravity,
largeur, Atmosphere 4 profils, grave mono, Mid Pan (centre seul), compresseur et Glue, clipper, limiteur, bypass
aligne et suréchantillonnage 2/4/8x modifiable pendant la lecture.
Banque : 17 presets Factory, dont 8 inspirations rap/electro/new rock/trap.
Reglages originaux, non approuves par les ingenieurs cites.
Sauver : donner un nom, puis choisir sa sauvegarde dans la section User.
Le bouton de rechargement actualise User ; les noms existants creent une copie.
Les fichiers restent dans %APPDATA%\BRI Audio Systems\BloodyMaster\User Presets.
La desinstallation ne supprime pas ces fichiers.

Votre interface HTML approuvee est integree ; son fichier original reste inchange.
Le moteur WebView2 est installe automatiquement si necessaire (Internet requis dans ce cas).
Valve combine relachement optical et coloration douce originale.
THD/XL, Tape Color Discret/Marque, de-harsh, Mud/Ring Traps et Spike Listen actifs.
Mesures : LUFS integre, court terme 3 s, true peak estime 4x, RAZ manuelle.
Comp. ecoute : OFF par defaut ; ecouter A et B au moins 3 s chacun.
Attenue le plus fort jusqu'a 12 dB ; mesures avant compensation.
COUPER Comp. ecoute avant export temps reel. Ignoree si rendu hors ligne
signale par l'hote. TARGET reste inactif : pas de normalisation automatique.
Cette version sert a tester le moteur et le VST3, pas a certifier une emulation analogique.

Verifier : chargement, mono/stereo, bypass sans decalage, automatisation,
sauvegarde/reouverture de session, presets et absence de craquements.
Le plafond ISP est teste sur des signaux numeriques ; verifier le master final
avec un mesureur de true peak/LUFS independant. Aucun niveau LUFS n'est garanti.

Desinstallation : Parametres Windows > Applications > BloodyMaster - Test VST3 x64.
L'outil WAV optionnel est installe dans Program Files\BRI Audio Systems\BloodyMaster.
Il cree une sortie a cote du WAV source, sans modifier celui-ci.

Protection globale active aussi en bypass et apres Comp. ecoute.
Plafond global -2 dBTP avec reserve ; regulation d'energie pour l'objectif -5 LUFS.
Verifier les LUFS integres du fichier complet ; aucune garantie universelle des encodeurs.
Latence a 48 kHz : 848 echantillons declares au DAW.

DELTA : ecoute entree alignee moins sortie de toute la chaine.
Transition 20 ms, latence inchangee ; parametres DSP inchanges.
Desactive par defaut et au rappel des presets/sessions.
Difference diagnostique brute : elle peut depasser le plafond du master.
Couper DELTA avant export temps reel. Force OFF en rendu hors ligne reconnu.
